# 일심교회 홈페이지

대한예수교장로회 일심교회 홈페이지입니다. GitHub Pages로 서비스합니다.

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 페이지 전체(화면 구성, 문구, 동작). 수정은 이 파일에서 합니다. |
| `support.js` | 페이지를 그려 주는 실행 엔진. 수정하지 않습니다. |
| `assets/` | 그림, 영상 칸 기본 표지, React 등 페이지가 불러오는 파일 |

## 예배 영상

각 칸은 방문할 때마다 유튜브 재생목록에서 가장 최근 영상을 찾아 연결합니다(주일예배는 2부 예배).
서버나 API 키 없이 방문자 브라우저에서 처리하며, 결과는 20분 동안 기억합니다.
